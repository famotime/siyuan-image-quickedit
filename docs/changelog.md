# 思源笔记插件“图片快剪”版本更新记录
## v1.0.8
### 新增
- 超级块图片合并支持“裁剪一致高度（以最小高度为准）”设置选项，合并多图时统一裁切对齐，避免因高度不一产生多余留白；
- 超级块图片合并支持识别编辑器中设定的排版宽度，按目标宽度等比例缩放并顶部对齐；
### 改进
- 优化长文档批量图片操作机制，解决延迟加载导致未渲染图片遗漏的问题；
- 增强批量任务处理与内核交互的稳定性，避免高频调用引发内核崩溃；

## v1.0.5
### 新增
  - 新增超级块图片合并间距和边框的个性化设置；
  - 支持多种“压缩策略”：综合比较（耗时长，默认）、优先压缩分辨率（耗时短）、优先压缩颜色（耗时短）；
### 改进
- 优化压缩性能；
- 修复本地编辑器打开图片时的资源路径匹配问题；

## v1.0.3
### 新增
- 新增超级块图片合并功能；
### 改进
- UI细节优化；

## v1.0.2

- 增加一个右键点击图片是否显示图片信息通知的开关；
### 改进

## v1.0.1

- 根据评审意见修改细节；

## v1.0.0
### 首版本发布
- 在图片点击右键，通过通知和菜单项，快速查看图片信息（分辨率、大小）；
- 支持单图快捷操作：转为 WebP、压缩到 50%、压缩到 30%、压缩到 10%；
- 默认原图不会删除，处理结果会插入到原图下方，供人工比对后处理；
- 支持文档级批量操作，对当前文档内全部图片一键处理；
- 更复杂的图片编辑需求，可以配置使用本机图片编辑软件打开，保存后自动刷新笔记内容。
